# Cover letters

- `_generic.md` is the source of truth. Mirror of the vault template.
- Tailored letters land here as `<company-slug>-<role-slug>.md` (e.g. `omnea-product-engineer.md`).
- Generate them with the `tailor-cover-letter` skill: `/tailor-cover-letter` (or just ask "draft a cover letter for <company>").

Nothing in this folder is served by the site. The phone number and other recipient-only details are fine here.
