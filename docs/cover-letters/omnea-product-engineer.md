## The letter

# Alex Boffey

alex@alexboffey.co.uk · alexboffey.co.uk

15 October 2026

Hi Joshua and Sunnah,

Thanks for the call today. As promised, here's my CV for the Product Engineer role. Your job description says engineers use Claude Code and agentic workflows every day, own projects from the first idea through to monitoring, and ship small changes several times a day. That's how I've worked for the last 18 months.

I've spent nine years building web products, most recently as a Senior Frontend Engineer at GEEIQ, an analytics platform for brands in gaming. I joined as the company moved off Ember.js. I led a team of four moving the main app to React, and the old one was gone in six months. I built the design system it runs on (40+ components across 296 files, two rebrands each shipped in a week) and the test setup around it (130+ Playwright tests sharded six ways in CI).

Over the last 18 months my work moved across the stack. Schema and API changes in Postgres through Prisma and tRPC. A Fastify service that runs our autonomous coding agent as Kubernetes jobs off signed webhooks, with a Kibana dashboard tracking each run. I also set the codebase up for the agents themselves (rules, custom skills, MCP integrations), so their output follows the same patterns and passes the same CI as the team's.

That's the work I want more of. I'm looking for a product engineering role where I own features from the problem through the API and data model to the UI, with frontend as my strongest side. Procurement is a good place for that. Approval flows that branch, tables people work in all day and forms that change with what's being bought all need the UI and the data model designed together.

There's more at alexboffey.co.uk. I can start within a couple of weeks, and I'm looking forward to the next stage.

Thanks,
Alex
